# Python Basic Syntax 📚🐍

Selamat datang di repository **Python Basic Syntax**!  
Repository ini berisi kumpulan script Python sederhana yang dibuat untuk belajar dasar-dasar pemrograman Python.

## 📂 Daftar File

- `aplikasikonversisuhu.py` → Program sederhana untuk konversi suhu (Celsius, Fahrenheit, Kelvin).
- `aritmatika.py` → Contoh operasi aritmatika dasar di Python.
- `tipedata.py` → Pengenalan berbagai tipe data di Python.
- `variable.py` → Contoh penggunaan dan deklarasi variabel.

## 📌 Tujuan

Project ini dibuat untuk:
- Mengenal sintaks dasar Python.
- Melatih logika pemrograman.
- Menjadi referensi belajar Python untuk pemula.
